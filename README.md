# Проект "Сортировка и манипуляция массивами в C"

В этом проекте реализованы несколько программ, решающих задачи, связанные с сортировкой массивов, математическими операциями и манипуляциями с данными. Каждое задание направлено на развитие навыков работы с массивами, указателями и алгоритмами сортировки, а также на улучшение навыков декомпозиции программ.

1. **Сортировка массива по возрастанию**:  
   Реализована программа, которая принимает массив из 10 целых чисел и сортирует его по возрастанию. Разделены функции для чтения данных, сортировки и вывода массива. Алгоритм сортировки был выбран с учетом ограничений, и массив передается в функции по указателю.

2. **Сравнение алгоритмов сортировки**:  
   В этой программе два различных алгоритма сортировки (быстрая и пирамидальная) используются для сортировки массива из 10 целых чисел. Результаты сортировки выводятся по очереди для каждого алгоритма. Программа не использует сторонние библиотеки и реализует алгоритмы сортировки с нуля.

3. **Манипуляции с массивом и вычисления**:  
   Программа принимает массив целых чисел, находит сумму четных элементов и формирует новый массив, состоящий из элементов, делящихся на эту сумму. Включены функции для работы с массивами и выполнения математических операций.

4. **Цикличный сдвиг массива**:  
   В этой программе реализован функционал цикличного сдвига элементов массива влево или вправо на заданное количество позиций. Массив передается в функцию по указателю, и изменения в нем выполняются с учетом переданных данных.

5. **Операции с большими числами**:  
   Программа для работы с большими числами, представленных в виде массивов цифр. Реализованы операции сложения и вычитания чисел, длина которых может достигать 100 цифр. Все операции проводятся с учетом декомпозиции и ограничений на использование сторонних библиотек.
