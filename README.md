# Проект "Математическая обработка данных и статистика"

Этот проект включает в себя несколько заданий, направленных на решение задач с использованием различных математических и статистических методов в языке C:

1. **Поиск максимума и минимума из трех чисел**:  
   Программа принимает три целых числа, находит максимальное и минимальное значения и выводит их на экран. В случае некорректного ввода выводится `n/a`.

2. **Возведение чисел в квадрат**:  
   Программа принимает массив целых чисел, возводит каждое число в квадрат и выводит результат. В случае некорректного ввода выводится `n/a`.

3. **Вычисление статистических метрик**:  
   Программа принимает массив целых чисел, выводит его, а затем вычисляет и выводит экстремумы (максимум и минимум), математическое ожидание и дисперсию, предполагая, что данные соответствуют дискретному равномерному распределению. Числа с плавающей запятой выводятся с точностью до 6 знаков после запятой. В случае некорректного ввода выводится `n/a`.

4. **Поиск числа, соответствующего статистическим критериям**:  
   Программа находит первое число в массиве, которое является четным, больше или равно математическому ожиданию, подчиняется правилу трех сигм и не равно нулю. Если такого числа нет, выводится 0. В случае некорректного ввода выводится `n/a`.

В ходе выполнения этих заданий была освоена работа с массивами, статистическими метриками и алгоритмами поиска в языке C. Программы придерживаются принципов декомпозиции, использование компактных функций для решения каждой задачи.
